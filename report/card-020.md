# CARD-020 · 双塔融合中的点击时间衰减

MIND-small 历史回放中，双塔加衰减热度的 Recall@100 为 **83.10%**，比双塔加等权热度高 **17.98 个百分点**，端到端 nDCG@10 从 **0.1715** 提高至 **0.2862**。两边使用相同候选池和 Top-100 预算。

## 方法与选参

用点击发生时间与评分时间的间隔计算时间权重。对每篇可见新闻，在评分前 24 小时内将点击按 1 小时半衰期加权求和。候选和点击状态按同秒批次更新，整组曝光先评分。等权组使用同一窗口的点击次数。两种热度均先做 `log1p`，再与双塔分数分别在同一可见池归一化。融合权重为热度 0.75、双塔 0.25。

在 small-train 的 31,393 条内部时序验证曝光上比较四个半衰期。选择规则是在端到端 nDCG@10 持平或改善的候选中取三种子平均 Recall@100 最高者。选出 **1 小时**并锁定后，复核 small-dev 历史回放。

| 方案 | Recall@100 | 端到端 nDCG@10 |
| --- | ---: | ---: |
| 24 小时等权热度 | 48.9503% | 0.053048 |
| 双塔 + 等权热度 | 51.1934% | 0.061228 |
| 双塔 + 衰减热度（1 小时） | 75.2750% | 0.226572 |
| 双塔 + 衰减热度（3 小时） | 69.9273% | 0.180630 |
| 双塔 + 衰减热度（6 小时） | 64.6105% | 0.143583 |
| 双塔 + 衰减热度（12 小时） | 59.3741% | 0.108173 |
